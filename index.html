Ready-to-use activities for your classroom

Every activity is a single self-contained page. Open it in any browser, project it, or hand out the link. Nothing to install, no student accounts, and it keeps working when the school Wi-Fi doesn't.

For teachers

  • Pairs and small groups

    Activities are designed for two or more learners working together at one device, so they suit a single projected Chromebook as well as individual phones.

  • Print-and-project friendly

    Large type, high contrast and a monochrome option, so slides stay legible on a washed-out projector or a photocopied worksheet.

  • No accounts, ever

    Nothing is collected and nothing is stored on a server. Student answers live in the page and disappear when the tab closes.

Add a resource

Activities are plain HTML files, so adding one is a two-minute job: create a folder, then add its entry to the list. Anyone can contribute — open a pull request.

  1. Create the folder

    Add my-activity/index.html at the repository root, using theme.css for the design tokens so it matches the rest of the site.

  2. Add one list entry

    Append a title, link, subject, level and one-sentence summary to assets/js/resources.js. The card is generated for you.

  3. Commit and open a PR

    Push to a branch and open a pull request. GitHub Pages rebuilds the site on its own.
